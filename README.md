Hotel Booking Management System

A command-line-based Hotel Booking Management System developed using Bash Scripting as part of our Scripting Workshop Assignment.

Project Overview

The Hotel Booking Management System aims to simplify and automate the basic operations involved in managing a hotel. The application provides a command-line interface through which hotel administrators can manage rooms, customers, reservations, check-ins, check-outs, and billing.

The system uses text files for data storage and Bash scripts to implement the various functionalities.

Objectives

Develop a functional hotel management application using Bash scripting.
Implement modular programming by separating functionalities into individual scripts.
Understand file handling and data management in Linux.
Apply conditional statements, loops, functions, and command-line utilities.
Gain practical experience with Git and GitHub for collaborative software development.

Features

The system is designed to support the following functionalities:

1. Room Management

- Add new rooms.
- View available rooms.
- Update room details.
- Remove rooms.

2. Customer Management

- Register new customers.
- View customer details.
- Update customer information.
- Search for existing customers.

3. Booking Management

- Create room reservations.
- View booking details.
- Modify existing reservations.
- Cancel bookings.
- Check room availability.

4. Check-in and Check-out

- Check in registered customers.
- Process customer check-outs.
- Update room availability after check-out.

5. Billing and Invoicing

- Calculate booking charges.
- Generate customer invoices.
- Maintain payment records.

6. Reports

- Generate booking reports.
- View room occupancy information.
- Generate revenue summaries.
